# Skill: Backend, APIs y Base de Datos

## Reglas Técnicas
1. **Seguridad**: Sanitizar todas las enradas para prevenir inyecciones SQL y ataques XSS
2. **Estructura de Respuesta**: Responder siempre son JSON estandarizado contenido `success`, `data` y `error`.
3. **Códigos de Estado HTTP**: Utilizar los códigos apropiados (200 OK, 201 Created, 400 Bad Request, 401 Unauthorized, 500 server Error).
4. **Manejo de Transaciones**: Asegurar la integridad de los datos de trámites complejos.
