# Skill: Pruebas Automatizadas

## Reglas de Cobertura
1. **Lógica de Negoco Crítica**: Todo cálculo de tasas, validación de identidad o regisro de trámites debe tener pruebas unitarias.
2. **Casos Bored (Edge Cases)**: Probar campos vacíos, entradas maliciosas o datos fuera de rango.
3. **Mocks de Servicios Externos**: Aislar las pruebas de la base de datos o APIs externas durante la ejecución de los tests.
